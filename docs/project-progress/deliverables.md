# Academic deliverables checklist

Academic evaluation phases differ from the five development branches. Do not
mark the submission complete until required human artefacts are present.

## Phase I — 30 percent

| Requirement | Status | Evidence or action |
|---|---|---|
| Abstract, literature review, proposed solution, contributions, references (10 marks) | Draft | docs/project-report/phase-1-report.md; confirm academic cutoff and export required IEEE layout |
| Prototype video <=5 minutes introducing five members (15 marks) | Pending | Script in docs/project-report/demo-video.md; record/upload actual video |
| Report, prototype files, artefacts and video link on GitHub (5 marks) | Partial | Code/docs present on phase branches; report draft and real video link must be reviewed/published |
| Genuine individual contributions | Partial | Four members' accepted phase histories; Rudraksh contribution pending |

## Phase II — 70 percent

| Requirement | Status | Evidence or action |
|---|---|---|
| Working ten-instruction subset | Verified within tested scope | rtl/, programs/, reports/verification/phase-5-manifest.json |
| Testbenches and waveforms | Verified/generated | tb/, make wave; selected graphical screenshots pending if required |
| Synthesis/resource report | Generic results | reports/synthesis/phase-5.md; FPGA mapping/timing not measured |
| Performance observations | Documented limits | Final report VI; CPI=1 ideal model, no Fmax claim |
| Final report including results, conclusion and references | Draft | docs/project-report/final-report.md; Rudraksh author review and IEEE PDF export pending |
| Continued Git history | Phase branches | Never merge into main; Phase-5 push needs explicit approval |
| Final artefacts/demo video | Pending | Submission index and script; real recording needed |
| Individual contribution completion | Pending Rudraksh | Own substantive docs/artefact commits using verified identity |
| Interview readiness | Personal task pending | docs/project-report/interview-preparation.md for all members |
| FPGA hardware demonstration | Not performed; optional unless required by institution | Need chosen board, constraints, memory adaptation, implementation and actual hardware evidence |

Source hashes establish which files were tested. Commit counts are not coverage
or proof of understanding. Preserve historical evidence and disclose assistant help.
