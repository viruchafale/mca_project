# Single-Cycle RV32I Processor

College project by Viraj, Kaustubh, Pratyush, Rudraksh and Bhargav.

**Current development milestone: phase-3 (arithmetic CPU integration).**
The core executes ADD, SUB, AND, OR, XOR and ADDI. LW/SW/BEQ/BNE remain for phase-4.
The `main` branch is intentionally left at its original commit.

## What is implemented

- 32-bit program counter, synchronous active-high reset, enable/hold and configurable reset address.
- Separate 1 KiB asynchronous instruction ROM with byte-address range/alignment checks.
- Valid ROM padding uses RV32I NOP (`00000013`); invalid fetches expose `address_valid=0`.
- Verilog-2001 RTL, SystemVerilog self-checking benches, Python runner and Make targets.
- Fetch fixture with assembly and a complete 256-word hexadecimal ROM image.
- 32 x 32 register file with protected x0 and synchronous reset.
- Combinational I/S/B immediate generator with explicit format selection.
- Checked 1 KiB data RAM with asynchronous read, synchronous write and reset preservation.
- Independent encoding checks for ten hand-calculated target instruction words.
- Five-operation ALU, exact arithmetic decoder, writeback mux and integrated arithmetic CPU.
- Sticky fetch/illegal-instruction diagnostic faults with write suppression and reset recovery.

The original fetch test still checks PC/ROM composition. The new CPU test executes
seventeen arithmetic instructions and checks the architectural register results.

## Run

Requirements: Python 3.9+, Git, Icarus Verilog (`iverilog` and `vvp`) on PATH.
On macOS, Icarus is available from Homebrew as `icarus-verilog`; install it if needed.

```bash
make test
make wave
python3 tools/run_tests.py --wave --self-check
make lint
```

Run from the repository root. All output stays under ignored `build/`:
`verification.json`, compilation/simulation logs, executables and optional VCDs.
Open `build/tb_fetch.vcd` in GTKWave to inspect reset, PC hold and ROM fetches.
Raw waveforms are generated by the simulator, not supplied as fabricated evidence.

Custom tool paths are supported:
```bash
IVERILOG=/path/to/iverilog VVP=/path/to/vvp make test
```
For a relocated Icarus package, set `IVL_BASE` to its `lib/ivl` directory too.
Do not commit machine-specific paths or downloaded tool binaries.
